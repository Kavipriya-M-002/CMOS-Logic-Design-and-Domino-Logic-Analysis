# CMOS Logic Design and Domino Logic Analysis

## 🔍 Overview
This mini project focuses on the design and simulation of three-input NAND and NOR gates using 45 nm CMOS technology. It includes voltage transfer characteristic (VTC) analysis, transistor sizing, and propagation delay evaluation for different input combinations. The project also explores domino logic by implementing the Boolean function \(Y = (AB+C)'\) and studying the effects of charge leakage, charge sharing, input glitches, and clock feed-through on circuit behavior.

## 🛠️ Tools & Technologies

| Category | Tools / Technologies |
|---|---|
| Design and Simulation | Cadence Virtuoso |
| Analysis | DC and Transient Analysis |
| Technology | 45 nm CMOS |
| Circuit Design | NAND, NOR and Domino Logic |

## ⚙️ Key Activities
- Designed three-input NAND and NOR circuits and analyzed their voltage transfer characteristics.
- Performed DC and transient simulations to study circuit response.
- Evaluated pull-up and pull-down delays for input combinations from 000 to 111.
- Conducted transistor sizing analysis to study inverter-equivalent delay.
- Implemented the Boolean function \(Y = (AB+C)'\) using domino logic.
- Simulated the effects of input glitches, charge leakage, charge sharing, and clock feed-through.

## 🎯 Key Takeaway
Gained practical experience in CMOS circuit design, transistor sizing, timing analysis, and dynamic logic behavior using Cadence Virtuoso.
