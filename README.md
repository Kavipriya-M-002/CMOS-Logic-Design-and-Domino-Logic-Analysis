# CMOS Logic Design and Domino Logic Analysis

## 🔍 Overview
This mini project explores the design and simulation of three-input NAND and NOR gates, along with a domino logic circuit, using 45 nm technology. The project analyzes voltage transfer characteristics, propagation delays, and dynamic logic effects such as charge leakage, charge sharing, input glitches, and clock feed-through.

## 🛠️ Tools & Technologies
- **Design Tool:** Cadence Virtuoso
- **Simulation:** Transient and DC analysis
- **Technology:** 45 nm CMOS

## ⚙️ Key Activities
- Analyzed the voltage transfer characteristics of three-input NAND and NOR gates.
- Studied pull-up and pull-down delays for different input combinations.
- Implemented the Boolean function \(Y = (AB+C)'\) using domino logic.
- Investigated the effects of input glitches, charge leakage, charge sharing, and clock feed-through through simulation.
